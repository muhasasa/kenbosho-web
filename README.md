# Kenbosho web sitesi

Kenbosho (Barış Gedik) için Türkçe, duyarlı, bağımlılıksız statik sanatçı sitesi.

## Çalıştırma

`index.html` dosyasını tarayıcıda açın. Yerel geliştirme sunucusu isterseniz proje klasöründe `python3 -m http.server 8080` çalıştırıp `http://localhost:8080` adresini açın.

## İçerik güncelleme

Sanatçı tarafından onaylanmış yayınlar, tarih, görsel, dinleme ve sosyal bağlantıları ilgili HTML sayfalarındaki açık placeholder alanlarıyla değiştirin. Formlar tasarım demosudur; gönderim için bir form servisi veya sunucu ucu eklenmelidir.
